# 🔍 Network Scanner
A Python tool that scans ports and detects HTTP/HTTPS services.

# 🚀 Features
- Port scanning
- HTTP detection
- HTTPS support (SSL)
- Displays server response
# 🧰 Technologies
- Python
- socket
- ssl
# ▶️ Usage
Run the script:
```bash
python scanner.py
```md
Enter target domain(ex: google.com) to scan open ports and detect services
